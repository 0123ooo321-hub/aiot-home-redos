# Протокол программных проверок

Дата: 20.11.2026. Версия приложения: 1.0.0.

Среда фактической проверки: Windows, Python 3.12.14, Node.js из рабочего окружения Codex, браузер Chromium. Запуск непосредственно в РЕД ОС и проверка ярлыка Linux не проводились. Совместимость с РЕД ОС основана на переносимом Python 3.7+ и веб-интерфейсе без Windows API. Контрольный запуск на целевой РЕД ОС остаётся обязательным.

| Проверка | Результат |
|---|---|
| 9 автоматических тестов модели: прогноз, пропуски, смена режима, блокировки, Эко, экономика, длительный расчёт | Пройдены |
| 3 теста HTTP-сервера: файлы интерфейса, запрет посторонних путей, запрет чужого Host | Пройдены |
| launcher.py --check | 6 файлов интерфейса найдены |
| Компиляция install.py | Синтаксических ошибок нет |
| Браузер: душная аудитория | 1200 ppm, виртуальная вентиляция включена |
| Браузер: открытие окна | Прогноз отключён до набора новых точек |
| Браузер: +5 минут проветривания | Показания пересчитаны, прогноз восстановлен |
| Браузер: потеря связи | Показания скрыты, прогноз и управление заблокированы |
| Браузер: 5 помещений | 32 000 ₽ затрат, 15 179,52 ₽/год после энергии хаба, 2,11 года |

Все проверки выполнены на синтетических данных. Нет результатов подключения физических датчиков, точности прогноза на натурных измерениях или измеренной экономии. Стенд ESP32/MQTT/Home Assistant описан как дальнейшее развитие.

Для приёмки на РЕД ОС: распаковать ZIP, выполнить bash start.sh, проверить все готовые ситуации, экспорт JSON и повторный запуск без интернета. Версию ОС, Python и браузера записать в отдельный протокол.
