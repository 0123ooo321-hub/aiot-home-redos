# Умный дом для всех — приложение для РЕД ОС

Учебный программный прототип конкурсного проекта Савченко Всеволода Дмитриевича (ИС2-25, Люберецкий техникум). Версия 1.0.0.

**Это симулятор:** датчики и исполнительные устройства виртуальные. Подключение ESP32, MQTT и Home Assistant пока не реализовано. Прогноз статистический, не нейросеть.

[Открыть веб-демо](https://0123ooo321-hub.github.io/aiot-home-redos/web/) · [Скачать проект ZIP](https://github.com/0123ooo321-hub/aiot-home-redos/archive/refs/heads/main.zip)

## Запуск на РЕД ОС

Нужны Python 3.7 или новее и современный Firefox/Chromium. Python доступен в официальном репозитории РЕД ОС. Интернет нужен только для скачивания проекта и недостающих компонентов. После скачивания приложение работает локально без облака.

1. Нажмите **Code → Download ZIP**, распакуйте архив.
2. Откройте терминал в распакованной папке.
3. Выполните `bash start.sh`. Браузер откроет `http://127.0.0.1:8765/`.
4. Для остановки нажмите Ctrl+C в терминале.

Если порт занят: `bash start.sh --port 0`. Если браузер не открылся, перейдите по адресу из терминала. Прямой вариант: `python3 launcher.py`. Сервер слушает только 127.0.0.1 и отдаёт только файлы интерфейса. Проброс портов и права администратора не нужны.

Необязательная установка ярлыка в меню: `python3 install.py`. Файлы размещаются в `~/.local/share/aiot-home-redos`, команда запуска — `~/.local/bin/aiot-home-redos`. Установка не меняет системные пакеты.

Самый простой режим без Python: открыть `web/index.html` в браузере. Основные функции работают и в этом режиме, но сохранение настроек для file:// зависит от браузера.

## Что можно проверить

- Панель температуры, влажности, CO₂ и виртуальной мощности.
- Линейный прогноз CO₂ на 15 минут по последним 15 модельным минутам.
- Сценарий вентиляции после 2 минут превышения рабочего порога.
- Блокировку обогрева при открытом окне, потере связи и 30 минутах без людей.
- Готовые ситуации: душная аудитория, проветривание, отсутствие людей, потеря связи.
- Журнал событий и экспорт истории в JSON.
- Калькулятор эффекта с учётом капитальных затрат и потребления общего хаба.

Модель на паузе при открытии. Кнопка «+5 минут» позволяет проверить сценарий без ожидания. При непрерывном запуске 2 секунды равны одной модельной минуте. Настройки сохраняются в localStorage текущего браузера. Показания и журнал сеанса сохраняются через экспорт.

## Алгоритм и ограничения

Прогноз строится методом наименьших квадратов: v = Σ(t−t̄)(C−C̄) / Σ(t−t̄)², прогноз = C̄ + v × (tсейчас + 15 − t̄). Требуются минимум 5 точек на интервале не меньше 4 минут. Последняя точка не должна быть старше 2 модельных минут. После открытия/закрытия окна используется только новая история. При потере связи прогноз отключается.

Концентрация в симуляторе обновляется упрощённой моделью: Cслед = C + 6 × число людей − k × (C − 420), где k равен 0,12 для окна, 0,07 для вентиляции и 0,007 для базового обмена. Коэффициенты выбраны для учебной демонстрации, не откалиброваны по реальному помещению. Прогноз ограничен диапазоном 420–5000 ppm.

Порог 1000 ppm — настраиваемый ориентир проекта, не универсальная граница безопасности. Приложение не является измерительным прибором или системой защиты. Уровень точности и реальная экономия не подтверждены натурными испытаниями.

Экономика: T = K / (n × E × s × c − P × 8760 × c). При эффекте ≤ 0 срок окупаемости не рассчитывается. Монтаж, энергия узлов, ремонт и труд сопровождения не включены.

## Проверки

`node --test tests/model.test.cjs` — автоматические тесты расчётов и сценариев (Node нужен только разработчику для тестов). `python3 launcher.py --check` — проверка комплектности. Подробности проверок и ограничения среды — в [docs/TEST_REPORT.md](docs/TEST_REPORT.md).

Код рассчитан на РЕД ОС, проверка непосредственно в установленной РЕД ОС пока не проведена. Это переносимая веб-реализация без Windows API, npm/pip зависимостей и Docker. На целевом компьютере требуется контрольный запуск по инструкции.

## Структура

- `web/` — автономный интерфейс, расчётная модель и логотип учебного учреждения.
- `launcher.py`, `start.sh`, `install.py` — локальный запуск и установка для пользователя Linux.
- `tests/` — проверки модели.
- `docs/` — конкурсная работа, презентация на 10 слайдов и протокол проверок.

Логотип Люберецкого техникума используется только для обозначения учебного учреждения. Права на логотип принадлежат его правообладателю.
